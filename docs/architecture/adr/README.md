# Architecture Decision Records

Architecture Decision Records (ADRs) halten wichtige technische und strukturelle Entscheidungen mit Kontext und Folgen dauerhaft nachvollziehbar fest.

## Verwendung

1. [ADR-Template](../ADR_TEMPLATE.md) kopieren.
2. Die nächste fortlaufende Nummer und einen kurzen Dateinamen verwenden.
3. Kontext, Entscheidung, Folgen und erwogene Alternativen ausfüllen.
4. Den Status bei einer späteren Ablösung aktualisieren und auf das neue ADR verweisen.
