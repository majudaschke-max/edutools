# Definition of Done

Eine Funktion gilt erst als fertig, wenn:

- die vereinbarten Anforderungen erfüllt sind,
- sie auf Smartphone, Tablet und Desktop funktioniert,
- die Tastaturbedienung geprüft wurde,
- keine kritischen Konsolenfehler auftreten,
- die lokale Speicherung getestet wurde, sofern sie relevant ist,
- Fehlerzustände verständlich behandelt werden,
- sie dem Design System entspricht,
- die Dokumentation aktualisiert wurde,
- keine unnötigen Abhängigkeiten eingeführt wurden.

Ein Nachweis kann je nach Umfang aus dokumentierten manuellen Testfällen, automatisierten Tests oder beidem bestehen.
