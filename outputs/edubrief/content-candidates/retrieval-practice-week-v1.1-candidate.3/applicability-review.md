# Anwendbarkeitsreview

Status: **PASS für externes Review**.

- Jede Karte enthält eine fachübergreifende, eine englischbezogene und eine BwR-bezogene Umsetzung.
- Fachübergreifend: für jedes Profil geeignet.
- Englisch: nur für `english`; BwR: nur für `bwr`.
- Mehrfachprofile erhalten die Vereinigung passender Umsetzungen in redaktioneller Reihenfolge, höchstens drei.
- Profile ohne eigene Fachvariante behalten die fachübergreifende Umsetzung.
- Es gibt keine duplizierte Mehrfachfach-Idee und keine Quote pro Fach.
- Der Fachfilter darf ausschließlich die Umsetzungen filtern; der wissenschaftliche Kartenkern bleibt unverändert.
