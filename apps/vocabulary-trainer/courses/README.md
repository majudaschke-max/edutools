# Kursdaten

Dieser Bereich ist für später veröffentlichte Kurskonfigurationen und Vokabeldaten vorgesehen. Im Foundation-Sprint werden keine echten Kurs- oder Vokabeldaten angelegt.

## Grundregeln

- Kursdaten bleiben von Programmlogik getrennt.
- Daten folgen später klar definierten und validierbaren JSON-Strukturen.
- Es werden keine vertraulichen oder urheberrechtlich ungeklärten Inhalte eingecheckt.
- Veröffentlichte Trainer enthalten nur den jeweils vorgesehenen Kursumfang.

Die Architekturentscheidung ist in [ADR-003](../../../docs/architecture/adr/ADR-003-code-and-content-separation.md) dokumentiert.
