# ByCS-Abnahme – SCORM-1.2-Lernpaket

Diese Vorlage wird für jedes reale private Paket ausgefüllt. Lokale Tests oder
ein API-Mock gelten nicht als erfolgreiche ByCS-Abnahme.

## Paketdaten

- Paket-ID:
- Deployment-ID:
- Kurs-ID:
- Paket-SHA-256:
- ByCS-Kurs/Interne Referenz, keine Zugangsdaten:
- Testdatum:
- prüfende Person:

## Upload

- [ ] bisherige fehlerhafte Aktivität wurde nicht wiederverwendet.
- [ ] eine vollständig neue Lernpaket-/SCORM-Aktivität wurde angelegt.
- [ ] ByCS-Kurs geöffnet.
- [ ] Bearbeitung eingeschaltet.
- [ ] Aktivität „Lernpaket“ hinzugefügt.
- [ ] erzeugte SCORM-ZIP hochgeladen.
- [ ] Paket gespeichert.
- [ ] Aktivität als Lernender oder über geeignete Vorschau geöffnet.
- [ ] keine alte Aktivitäts-URL oder altes Lesezeichen wurde wiederverwendet.

## Start

- [ ] App wird angezeigt und nicht als Datei heruntergeladen.
- [ ] keine Meldung „Ungültige Kursmodul-ID“ erscheint.
- [ ] keine Dateien oder Assets fehlen.
- [ ] keine CSP- oder Sicherheitsfehler erscheinen.
- [ ] der korrekte Kurs wird angezeigt.
- [ ] keine Autoren-, Kurswechsel-, Import- oder Exportfunktion ist sichtbar.

## Lernen

- [ ] Flashcards Source → Target funktionieren.
- [ ] Flashcards Target → Source funktionieren.
- [ ] Gemischt funktioniert und bleibt pro Karte stabil.
- [ ] Quiz wurde regulär beendet.
- [ ] Schreiben wurde regulär beendet.
- [ ] Speed Challenge wurde bis zum Zeitende geprüft.
- [ ] Source-Aussprache funktioniert, sofern Browserstimme vorhanden.
- [ ] Scaffolding stammt aus der Source-Sprache.
- [ ] Target-Inhalte besitzen kein Audio.

## SCORM

- [ ] neuer Versuch beginnt bei entsprechender Policy als unvollständig.
- [ ] bloßes Öffnen setzt nicht `completed`.
- [ ] eine reguläre Lernsession wurde vollständig beendet.
- [ ] Aktivität wurde verlassen.
- [ ] ByCS-Bericht beziehungsweise Aktivitätsstatus wurde geprüft.
- [ ] erneutes Öffnen erzeugt keine doppelte Initialisierung.
- [ ] kein technischer SCORM-Hinweis erscheint.
- [ ] Abbruch einer Session setzt nicht `completed`.

## Persistenz und Update

- [ ] ein Wort wurde gelernt oder markiert.
- [ ] Aktivität wurde geschlossen und erneut geöffnet.
- [ ] lokaler Lernstand blieb vorhanden.
- [ ] Version 2 verwendet gleiche Deployment-, Kurs- und stabile Wort-IDs.
- [ ] Version 2 wurde in ByCS ersetzt.
- [ ] vorhandener Lernstand blieb erhalten.
- [ ] ein neues Wort erschien ungelernt.
- [ ] ein archiviertes Wort wurde nicht mehr angeboten.
- [ ] eine neue Deployment-ID erzeugte bei Bedarf getrennten Lernstand.

## Responsive und Accessibility

- [ ] 320 × 700 ohne horizontalen Überlauf.
- [ ] 375 × 812 ohne horizontalen Überlauf.
- [ ] 768 × 1024 ohne horizontalen Überlauf.
- [ ] 1440 × 900 ohne horizontalen Überlauf.
- [ ] Tastatur, Fokus, Skip-Link und Dialoge funktionieren.
- [ ] 200-%-Reflow bleibt nutzbar.
- [ ] keine Konsolenfehler und keine fehlgeschlagenen Assetrequests.

## Grenzen

- [ ] auf einem zweiten Browser oder Gerät ist der lokale Detailstand nicht
      automatisch vorhanden.
- [ ] SCORM-Abschluss wird nicht als vollständige fachliche Bewertung verstanden.
- [ ] es werden keine Wortergebnisse in ByCS erwartet.
- [ ] das Paket wurde als technisch einsehbar und nicht als DRM dokumentiert.

## Ergebnis

- [ ] bestanden
- [ ] nicht bestanden

Beobachtungen und notwendige Korrekturen:

Falls der Start erneut fehlschlägt: Screenshot, Zeitpunkt, verwendeter neuer
ZIP-Dateiname, sichtbare ByCS-/Moodle-Fehler-URL ohne Zugangsdaten und die
Browserkonsole festhalten.
