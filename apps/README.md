# EduTools Apps

Dieser Bereich enthält die fachlichen Produkte der EduTools-Familie. Jede App besitzt ihre eigene Produktdokumentation, Programmlogik und getrennte Kursdaten. Gemeinsame, bewährte Grundlagen können aus dem [EduTools Core](../core/README.md) verwendet werden.
